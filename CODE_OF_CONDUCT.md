# Code of Conduct

This project adopts the [Contributor Covenant Code of Conduct](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In summary: be welcoming and respectful, accept constructive criticism gracefully, focus on what is best for the community, and show empathy toward other community members. Harassment, trolling, personal attacks, and publishing another person's private information are not acceptable.

## Enforcement

Report unacceptable behaviour by opening an issue in this repository (without private details) or by contacting the repository owner through GitHub. Maintainers may remove comments, close issues or pull requests, or ban participants who violate this code.
